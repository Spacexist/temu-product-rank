# 主图余弦去重（HTML 阶段）

## 背景

模型按「预测分」排序后，Top 区里常出现**同款换色 / 换印花**（收纳箱、午餐袋等）。标题不同、销量不同，分数仍会挤进 Top 5%，但主图几乎一样。  
去重只在 **生成 HTML / Top CSV** 时做，**不改** `*_scored.csv` 里的原始预测分与排名，便于对照和继续训练。

## 做法

1. **向量**：与预测相同，ResNet18 主图 512 维，L2 归一化。
2. **分组**：在每个 **一级类目 + 二级类目** 内分别去重（三个一级类目都会跑；不是只厨房）。
3. **贪心保留**：组内按 `预测分` 从高到低扫描；若与已保留商品的 cos ≥ 阈值，则视为视觉重复并**沉底**。
4. **同 URL**：主图 URL 去掉 `?`/`#` 后相同，直接视为重复（不必算 cos）。
5. **缺图**：本地 `D:\temu_images` 无缓存时，去重阶段会**补下载**（并发见 `config.json` 的 `dedupe_download_concurrency`），再 embed；仍失败的行不参与 cos，但同 URL 规则仍生效。
6. **加速**：`run.py` 预测结束会在 `screener/output/{stem}_img512.npz` 写出当日主图向量；`generate_html.py` 优先读该文件，避免 HTML 阶段重算一遍。

沉底方式：`visual_dup` 标记 + 页面排序用 `score = -1e9`，分享页 Top 5% / `_Top.csv` 默认排掉；筛选页仍可见，便于人工删。

## 默认参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--img-dedupe` | `0.92` | cos 阈值；`0` 关闭 |
| `--img-dedupe-scope` | `all` | `all` = 全部分组；`kitchen` = 仅「家居厨房用品」下各二级 |

阈值越高越严（只去几乎一样的图）；同款不同角度/轻微改色可试 **`0.88`**。

## 命令

日更已默认开启（`pipeline/daily.py` → `generate_html.py`）：

```bat
python screener\src\generate_html.py --input screener\output\20260919_merged_scored.csv --out-dir output --top-pct 5
```

手动调阈值：

```bat
python screener\src\generate_html.py --input screener\output\20260919_merged_scored.csv --out-dir output --img-dedupe 0.88 --img-dedupe-scope all
```

仅厨房二级：

```bat
python screener\src\generate_html.py --input ... --img-dedupe 0.92 --img-dedupe-scope kitchen
```

关闭：

```bat
python screener\src\generate_html.py --input ... --img-dedupe 0
```

控制台会打印各 `一级/二级` 的候选条数、embed 成功数、沉底条数。

## 代码位置

| 文件 | 职责 |
|---|---|
| `screener/src/img_dedupe.py` | 向量加载、补下图、分组贪心去重、`demote_rows` |
| `screener/src/generate_html.py` | CLI、`--img-dedupe*`、调用去重后再 `render` / `render_share` |
| `screener/src/run.py` | 写出 `{stem}_img512.npz` 供去重复用 |
| `screener/config.json` | `image_cache_dirs`、`dedupe_download_concurrency`、`embed_batch` |

## 与训练去重的区别

训练切分里的 `image_cosine>0.98`（见 `REVIEW.md`）只作用于 **test 集防泄露**，和 HTML 展示的 **0.92 业务去重** 无关，阈值与目的都不同。
